# board_pcba — RP2350 / PCM5102A 直載せ基板

JLCPCB の **Economic PCBA** で組み立てる pico-opm-writer の基板。Raspberry Pi Pico 2 と
GY-PCM5102 のモジュールを使わず、RP2350A・PCM5102A・周辺部品を直接実装する。
モジュール側に重複していた電源回路・USB・水晶を基板側へ統合してある。

**ファームウェアのピン割り当ては [README.md](../README.md) §1.1 の接続表と同一。**
`src/opm.h` の `OPM_PIN_*` / `src/ym3012.h` の `YM3012_PIN_*` / `src/button.h` の
`BUTTON_PIN_*` はそのまま使える。

現時点の成果物は**回路図だけ**で、基板レイアウト（`.kicad_pcb`）は未着手。

## 2. 回路の構成

```
USB-C VBUS ─┬─ +5V ─┬─ U4 AMS1117-3.3 ── +3V3   RP2350A / フラッシュ / PCM5102A デジタル
            │       ├─ U5 XC6206P332  ── +3.3VA PCM5102A の AVDD / CPVDD
            │       └─ U6 YM2151 VDD
            └─ C1 10uF + C2 100nF

+3V3 ─ U1 VREG_VIN ─┐ RP2350 内蔵スイッチングレギュレータ
      ─ R9 33Ω ─ VREG_AVDD（C9 4.7uF）
                VREG_LX ─ L1 3.3uH ─ VREG_FB = +1V1 ─ DVDD ×3
```

回路図のブロック分け:

| ブロック | 内容 |
| --- | --- |
| A. USB-C ・ 電源 | J1、CC プルダウン、USB 直列終端、U4 / U5 の 2 系統 LDO |
| B. クロック ・ フラッシュ ・ 起動 | X1、U2、BOOTSEL (SW4)、RESET (SW3) |
| C. RP2350A | U1、デカップリング、内蔵レギュレータの外付け部品 |
| D. YM2151 (OPM) | U6、/CS プルアップ、デカップリング |
| E. PCM5102A ・ 音声出力 | U3、I2S 直列抵抗、チャージポンプ、出力フィルタ、J2 |
| F. ユーザー I/F ・ デバッグ端子 | SW1 / SW2、LED、SWD / UART / DAC プローブ、取付穴 |

ブロック間はネットラベルだけでつないである。ネット名は現行 [board/](../board/) を踏襲し、
I2S のみ PCM5102A のピン名に合わせて `LRCK` としている。

### 2.2 PCM5102A

GY-PCM5102 の既定ジャンパ設定をハードワイヤしてある。

| ピン | 接続 |
| --- | --- |
| 1 CPVDD / 8 AVDD | `+3.3VA`（U5 の出力。100nF を各ピンに 1 個ずつ） |
| 20 DVDD | `+3V3`（100nF） |
| 18 LDOO | 内蔵 1.8V LDO の出力。100nF + 10µF で `GND` へ |
| 2 CAPP / 4 CAPM | 2.2µF のフライングキャパシタ |
| 5 VNEG | 2.2µF で `GND` へ |
| 12 SCK | `GND`（内蔵 PLL モード） |
| 16 FMT | `GND`（I2S） |
| 11 FLT | `GND`（Normal latency） |
| 10 DEMP | `GND`（De-emphasis off） |
| 17 XSMT | `+3V3`（soft un-mute） |
| 13 BCK / 15 LRCK / 14 DIN | 22Ω 直列で GP26 / GP27 / GP28 |
| 6 OUTL / 7 OUTR | 470Ω → J2.T / J2.R、各々 2.2nF で `GND` へ |

**CPVDD はチャージポンプの電源で、TI のデータシートは AVDD と同じアナログ 3.3V に置く**
（§10.1.1 の Figure 33、§11.1 の Table 12）。デジタル側から取ると、チャージポンプの
パルス電流がアナログ電源へ回り込む。

**470Ω + 2.2nF は TI のデータシートが指定するポストフィルタ**（fc ≈ 154kHz）。
TI は THD+N・SNR・チャンネルセパレーションの規格値をすべて
「10kΩ 負荷 + 470Ω 出力抵抗 + 2.2nF シャント」の条件で規定しているので省略しない。
出力はチャージポンプで GND センターになるため DC カットのコンデンサは要らない。

### 2.3 YM2151 の /CS プルアップ

**R11: `~{CS}` → `+3V3` に 1kΩ。** 電源投入から `opm_init()` が /CS を H にするまでの間、
RP2350 のパッドは入力＋内部プルダウンなので、これが無いと OPM が D0-D7 を駆動する窓ができる
（[README.md](../README.md) §1.3）。

プルアップ先を 5V ではなく **3.3V** にした理由:

- **YM2151 の全入力の VIH は min 2.0V**（TTL しきい値。VIL は max 0.8V、入力リークは
  Vi=10V で 0.1µA 以下）。**RP2350 の内部プルダウンは IOVDD=3.3V で 36kΩ〜113kΩ。**
- この 2 つから、`opm_init()` 前の /CS 電位は次のようになる。

  | プルアップ | R_PD=36k | R_PD=113k | VIH 2.0V への余裕 | /CS Low 時の吸い込み | GP11 の最大電圧 |
  | --- | --- | --- | --- | --- | --- |
  | +5V / 10kΩ | 3.91V | 4.59V | +1.9V | 0.5mA | **4.59V** |
  | +3V3 / 10kΩ | 2.58V | 3.03V | +0.58V | 0.33mA | 3.3V |
  | **+3V3 / 1kΩ** | **3.21V** | **3.27V** | **+1.2V** | 3.3mA | 3.3V |

- 通常動作では GP11 が 3.3V で /CS を駆動するので、5V にしても H レベルは良くならない。
  1kΩ なら起動直後も**通常駆動時と同じ電位**になる。
- 5V プルアップは、VBUS が立って 3.3V がまだ立ち上がり切っていない間、IOVDD 不足のまま
  GP11 へ 5V を流し込む。3.3V なら GP11 は 3.3V レールに追従するだけで IOVDD を超えない。
- 1kΩ は他でも使っているので部品番号が増えない。3.3mA は RP2350 の 1 ピンあたりの駆動能力
  （12mA）にも合計値（`I_IOVSS_MAX` 100mA）にも収まり、/CS が L になるのは
  バスサイクル中だけなので平均消費は無視できる。

3.3V レールの立ち上がり中の短い窓は塞げないが、それは現行 [board/](../board/) と同じ状態で、
README §1.3 の整理がそのまま当てはまる。POR 解除から `opm_init()` までの長いほうの窓は塞げる。

## 4. 部品選定：検討した選択肢と選定理由

### 4.1 サイズと価格

| 項目 | 選択肢 | 採用 | 理由 |
| --- | --- | --- | --- |
| チップ抵抗 | 0402 / 0603 | **0402 に統一** | Economic PCBA の最小サイズが 0402 |
| µF 級コンデンサ | 全部 0402 / 全部 0603 / 電圧で使い分け | **電圧で使い分け** | 0402 の Basic 品は 6.3V しかなく DC バイアスで大きく容量が減る。`+5V` と `+3V3` の 10µF は 0805/25V、`+3.3VA` と LDOO の 10µF は 0603/10V |
| VREG 周辺の 4.7µF | 0402 / 0603 | **0402** | RPi の設計ガイド §2.1 が 0402 (1005 metric) を指定。レギュレータのレイアウトが critical なのでサイズを勝手に大きくしない |
| タクトスイッチ | 5.1×5.1mm / 3.9×3×2mm | **C720477 (3.9×3×2mm)** | Basic かつ在庫 90 万個。KiCad 標準 `SW_SPST_TS-1088-xR020` がこの部品のデータシートから起こされている |

### 4.2 フラッシュ容量

| 選択肢 | 判断 |
| --- | --- |
| 2MB (W25Q16) | 曲データが約 1.7MB までで足りない |
| 4MB (W25Q32) | Pico 2 と同容量でファームウェアの変更が不要だが、**Extended 品しかなく 16MB の Basic 品より高い** |
| **16MB (W25Q128JVSIQ / C97521)** | **採用。** Basic で在庫 10 万個。RP2350 がサポートする最大容量で、RPi のリファレンス設計と同一部品。FatFs 領域が約 15.7MB になる（ファームウェア側の対応は §7） |

### 4.3 USB D+/D− の直列 27Ω

RPi の設計ガイド §5.1 が「USB のインピーダンス規格を満たすために 27Ω の直列終端が必要」と
明記している。**JLCPCB に Basic の 27Ω は 0402 / 0603 / 0805 のいずれにも無く**、手数料が
同じくかからない Preferred ティアにも無い。Basic の 0402 抵抗で選べる値は
0 / 10 / 22 / 33 / 49.9 / 100 / 120 / 200 / 220 / 330 / 470 / 510 / 1000 Ω の 13 種だけ。

| 個数 / 1 本あたり | 最良の組み合わせ | 実効値 |
| --- | --- | --- |
| 2 個 | 33 ∥ 200 | 28.32Ω (+4.9%) |
| 2 個 | 33 ∥ 120 | 25.88Ω (−4.1%) |
| 3 個 | 22 + (10 ∥ 10) | 27.00Ω（厳密） |
| 3 個 | 33 ∥ (49.9 + 100) | 27.05Ω (+0.2%) |

2 個では ±4% 以上ずれ、±1% に入れるには 1 本あたり 3 個（D+/D− で計 6 個）要る。
Extended 手数料は枚数に依存しない $3 なので 10 枚なら 1 枚あたり $0.30 にしかならず、
**USB はこの基板の唯一のホストインタフェースなので終端を分割してまで節約しない**。
33Ω 単体（R9 と共通化して新規部品ゼロ）も検討したが、+22% となり USB 2.0 フルスピードの
ドライバ出力インピーダンス規格（28〜44Ω、直列抵抗込み）を超える可能性がある。

### 4.4 RPi の設計ガイドに従った部分

RP2350 の内蔵スイッチングレギュレータ周辺は、RPi の設計ガイドが
「部品選定ごと真似しろ、外れるなら自己責任」と明記しているので全面的に合わせてある。

| 部品 | 選択肢 | 採用と理由 |
| --- | --- | --- |
| 12MHz 水晶 | Basic の 20pF 品 (C9002) / Extended の 12pF (C70565) / **ABM8-272-T3 (C20625731)** | **ABM8-272-T3。** ガイド §4 が名指しで推奨し、直列 1kΩ は「最大 ESR 50Ω・IOVDD 3.3V」に合わせて水晶を過大駆動しないよう選んだ値だと述べている。回路から外れると全温度域での検証が必要になる。負荷容量 15pF ×2 の直列 7.5pF に寄生 3pF を足して 10.5pF ≒ CL 10pF |

| QSPI_SS の 10kΩ | 実装 / **DNF** | **DNF。** ガイド §3.1「この特定のフラッシュ (W25Q128JVS) では外付けプルアップは不要と判明した。別のフラッシュを使うときのために footprint だけ用意してある」 |
| アナログ LDO | ME6211C33M5G (C82942) / SPX3819 (C9055) / **XC6206P332MR-G (C5446)** | **XC6206。** ME6211 は在庫 9 個で実質発注不可。XC6206 は Basic・在庫 45 万個で、200mA / ドロップ 250mV@100mA は AVDD の約 25mA に十分 |
| PCM5102A の電源 | LDO 1 個で共通 / フェライトビーズで分離 / **LDO 2 個** | **LDO 2 個。** RP2350 内蔵バックのスイッチングノイズをアナログ側から切り離す。追加は LDO 1 個とコンデンサ 2 個だけ。AVDD と CPVDD は TI のデータシートどおり同じ `+3.3VA` に載せ、DVDD だけ `+3V3` から取る |
| 10µF の置き場所 | 電源ピンごと / **レギュレータの入出力だけ** | **レギュレータの入出力だけ。** `+5V` は C1（U4 / U5 の入力）、`+3V3` は C3（U4 の出力）、`+3.3VA` は C6（U5 の出力）の 1 個ずつで、デカップリングバンクには置かない。RPI-RP2350A-MINIMAL と同じ配置で、AMS1117 / XC6206 が安定条件として要求する出力コンデンサもこれで満たす。各 IC のピン直近は 100nF が受け持つ |

## 5. レイアウト時の注意

RP2350 の設計ガイドから。回路図には現れないのでここに残す。

- **USB は 90Ω 差動。** 1mm 厚基板なら 0.8mm 幅・0.15mm ギャップ。**直下は切れ目のない GND**（§5.1）
- **R5 / R6（27Ω）は RP2350 の至近**、フラッシュ周りの R1 / R2 はフラッシュの至近（§3.1・§5.1）
- **`VREG_PGND` の大電流リターンは、他の GND を乱さずに PGND ピンへ直接戻す**（§2.1）
- **L1 は極性ドットの向きを RPi のレイアウトに合わせる**（§2.1）
- **水晶の配線は極力短く。** 寄生容量を 3pF と見込んで負荷容量を決めている（§4）
- 電源ピンごとに 100nF を至近に置く。53 / 54 ピンだけ 1 個を共用している（§2.2.1）
- SMD 部品はすべて表面に置く（Economic PCBA は片面実装）

PCM5102A のデータシート §12.1 から。

- **電源とチャージポンプのデカップリング（C26 / C27 / C28 / C29 / C30 / C31 / C32）は
  U3 の直近に置く**
- **I2S のクロック・データ配線を OUTL / OUTR から離す。** 高速クロックのリターン電流が
  アナログ出力に乗る
- `AGND` / `DGND` / `CPGND` は分離せず共通グラウンドでよい。表層を信号、裏層を GND ベタにする

`+5V` のバルクは U4 / U5 の入力側の C1 だけで、U6 の VDD には C25 (100nF) しか付いていない
（§4.4）。**J1 から U4 / U5 を経て U6 までの `+5V` を短く太く引く。**

## 7. ファームウェア側の未対応事項

16MB フラッシュを選んだので、この基板でファームウェアを動かすには次が要る。

- `PICO_FLASH_SIZE_BYTES` を 16MiB にする独自ボードヘッダ（`pico2.h` を include して上書き）
- `cmake ... -DFLASH_TOTAL_BYTES=16777216`

`src/flash_disk.c` の `_Static_assert` が両者の一致を検査するので、片方だけ変えると
コンパイルが落ちる。

## 8. 検証

実機は要らない。`kicad-cli` だけで完結する。

```bash
KC=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli

# ERC（エラー・警告とも 0 件であること）
$KC sch erc --severity-error --severity-warning --exit-code-violations \
    board_pcba/pico-opm-writer_pcba.kicad_sch

# ネットリスト
$KC sch export netlist --format kicadsexpr -o /tmp/pcba.net \
    board_pcba/pico-opm-writer_pcba.kicad_sch

# BOM（LCSC 番号と DNP が入っていること）
$KC sch export bom --group-by 'Value,Footprint,LCSC Part #' \
    --fields 'Reference,Value,Footprint,${QUANTITY},LCSC Part #,${DNP}' \
    -o /tmp/pcba-bom.csv board_pcba/pico-opm-writer_pcba.kicad_sch

# 目視用
$KC sch export pdf -o /tmp/pcba.pdf board_pcba/pico-opm-writer_pcba.kicad_sch
```
