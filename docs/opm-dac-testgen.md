# opm-dac-testgen

[tools/opm-dac-testgen.py](../tools/opm-dac-testgen.py)

[opm-dac2wav.py](opm-dac2wav.md) の回帰テスト。既知の PCM 波形を YM3012 のシリアルフォーマットへ
**エンコード**して疑似キャプチャ (`.bin`) を作り、それをデコーダに CLI 越しで食わせて、
出てきた WAV が元の PCM と完全一致するかを確かめる。

ビット順・SH1/SH2 の対応・冒頭の切り捨て・位相の自動判定・入出力経路をまとめて検査する。
実機もロジックアナライザも要らない（同種のものに
[opm-lfo-period-testgen.py](opm-lfo-period-testgen.md) と `test/dac_lr/lr_relation.py --self-test` がある）。

## 使い方

```bash
# 全テストを実行する（引数不要）
./tools/opm-dac-testgen.py

# 生成した疑似キャプチャと WAV を残して中身を見る
./tools/opm-dac-testgen.py --outdir /tmp/dactest

# デコーダの統計も表示する
./tools/opm-dac-testgen.py --verbose
```

出力:

```
* テストケース: 無音(1200) / フルスケール正弦(1200) / 極値(1200) / 微小振幅(1200) / 乱数(1200)
* 疑似キャプチャ 767807 サンプル (0.0960s 相当) / 先頭 210 サンプルを切り落とし
PASS 既定 (CH1=L/CH2=R)
PASS --swap (CH1=R/CH2=L)
PASS パイプ (stdin → stdout)
PASS zstd (stdin → .wav.zst)
```

**終了コードは失敗が 1 件でもあれば 1**、全部通れば 0。失敗した場合は最初に食い違った
フレーム番号と 16 進値を表示する。

## 引数

| オプション | 既定 | 説明 |
| --- | --- | --- |
| `--frames FRAMES` | `1200` | テストケース 1 種あたりのフレーム数 |
| `--seed SEED` | `20260808` | 乱数シード。開始位相・無効スロット・乱数波形に使う |
| `--outdir OUTDIR` | 一時ディレクトリ | 生成物を残すディレクトリ |
| `--verbose` | off | デコーダの標準エラー出力も `  \| ` 付きで表示する |

`--outdir` を指定すると次のファイルが残る。

| ファイル | 内容 |
| --- | --- |
| `selftest.bin` | 疑似キャプチャ（8MHz、bit0=φ1 / bit1=SO / bit2=SH1 / bit3=SH2） |
| `selftest.wav` | 既定でデコードした結果 |
| `selftest-swap.wav` | `--swap` でデコードした結果 |
| `selftest.wav.zst` | zstd 経路でデコードした結果 |

## 検査する内容

### 経路（4 ケース）

| ケース | 内容 |
| --- | --- |
| 既定 (CH1=L/CH2=R) | ファイル → ファイル。L/R の割り当てを含めて元 PCM と一致するか |
| `--swap` (CH1=R/CH2=L) | 同上。L/R を入れ替えた期待値と一致するか |
| パイプ (stdin → stdout) | 標準入出力経由の結果がファイル経由と**バイト単位で一致する**か |
| zstd (stdin → `.wav.zst`) | zstd 出力を展開した結果がファイル経由と一致するか |

パイプと zstd を別ケースにしているのは、実運用（[opm-writer.py](opm-writer.md) の `.wav.zst` 出力）が
パイプ経路を使うため。ファイル経由でしか検証していないと、そちらの壊れに気付けない。

### テスト波形（5 種）

| 波形 | 狙い |
| --- | --- |
| 無音 | 指数 `E` の下端 |
| フルスケール正弦 | L = 440Hz / 32000、R = 1234Hz / 4000 の非対称な組み合わせ |
| 極値 | `32704` (= `511 << 6`) と `-32768` の交互 |
| 微小振幅 | 指数の上端側と量子化 |
| 乱数 | 全域 |

### 実機に寄せた細工

疑似キャプチャは理想的な波形ではなく、実測で起きる条件を意図的に混ぜてある。

- **キャプチャ開始位置をランダムにずらす**（フレーム途中・φ1 サイクル途中から始まる）
- **φ1 とロジアナのサンプルレートを 25ppm ずらす**（1 相あたりのサンプル数が 1〜3 に揺れる）
- **無効スロット 3bit にランダム値を詰める**（デコーダが無視することの確認）

期待値との突き合わせでは、冒頭のずれを 0〜8 フレームまで許容する（デコーダは同期が
取れるまでの先頭を捨てるため）。

## 依存

- Python 3（標準ライブラリのみ）
- 同じディレクトリの **`opm-dac2wav.py`** — 無ければ終了コード 1 で終わる
- zstd ケースのみ **Python 3.14 以上**が必要。古い Python では `SKIP` 表示で飛ばし、
  残り 3 ケースだけ実行する
